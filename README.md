## Instalasi

1. Unduh `HALTE4D-Lucky-Spin.apk` melalui tombol atau QR di atas.
2. Saat Android meminta izin, aktifkan **Install unknown apps** untuk browser atau pengelola file yang digunakan.
3. Buka APK dan pilih **Install**.
4. Pembaruan berikutnya dapat dipasang di atas versi lama tanpa menghapus aplikasi.

Aplikasi membutuhkan koneksi internet. Verifikasi voucher, penentuan hadiah, pembatasan penggunaan, pencatatan spin, dan klaim tetap diproses oleh server HALTE4D; APK tidak menentukan hasil hadiah.

Setiap release menyertakan `HALTE4D-Lucky-Spin.apk.sha256`. Bandingkan SHA-256 APK dengan file tersebut sebelum instalasi.
